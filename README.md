# Лера — фотографии про тебя

Авторское портфолио фотографа из Нижнекамска. Статический сайт без сторонних JavaScript-зависимостей: фотоистории, фильтры, адаптивная навигация, просмотр серий, условия съёмки.

```sh
npm run dev
npm run check
npm run build
npm run preview
```

Локальный адрес: `http://localhost:4173`. Для публикации используется только `dist/`; исходная выгрузка Telegram, референсы и локальный анализ в неё не входят.

Данные историй: `src/stories.js`. Тексты: `index.html`. Визуальная система: `docs/brand-spec.md`. Шрифты и фотографии хранятся локально.

Сайт пока имеет `noindex`. Перед публичным запуском нужно подтвердить личный контакт для записи и актуальные условия, затем убрать `noindex` и обновить `public/robots.txt`.
