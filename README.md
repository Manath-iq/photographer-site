# Лера — фотографии про тебя

Авторское портфолио фотографа из Нижнекамска. Статический сайт без сторонних JavaScript-зависимостей: фотоистории, фильтры, адаптивная навигация, просмотр серий, условия съёмки.

Предпросмотр: https://manath-iq.github.io/photographer-site/

Публикация: GitHub Actions собирает `dist/` и отправляет в GitHub Pages при обновлении ветки `main`.

```sh
npm run dev
npm run check
npm run build
npm run preview
```

Локальный адрес: `http://localhost:4173`. Для публикации используется только `dist/`; исходная выгрузка Telegram, референсы и локальный анализ в неё не входят.

Данные историй: `src/stories.js`. Тексты: `index.html`. Визуальная система: `docs/brand-spec.md`. Шрифты и фотографии хранятся локально.

Личный контакт для записи: `@valeryankaph`. Пакеты и цены демонстрационные, придуманы по запросу Максима для показа оформления. Перед финальным запуском их нужно согласовать с Лерой. Сайт пока имеет `noindex`; после согласования условий можно убрать его и обновить `public/robots.txt`.
